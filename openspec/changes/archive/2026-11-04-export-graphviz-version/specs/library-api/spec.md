## ADDED Requirements

### Requirement: Graphviz version

The package SHALL name the version of Graphviz that it follows, as a constant that other Go programs can read. It SHALL be the version that the command line names in `-V` and that the SVG output names in its `Generated by graphviz version` comment.

#### Scenario: Same version everywhere

- **WHEN** a Go program reads the Graphviz version of the package, `dot -V` runs, and `digraph { a }` is rendered as `svg`
- **THEN** the version is `16.1.0`, `dot -V` writes `dot - graphviz version 16.1.0 (gogv VERSION)`, and the SVG holds `<!-- Generated by graphviz version 16.1.0 (gogv)`
