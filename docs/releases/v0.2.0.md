# gogv v0.2.0

This release exports the version of Graphviz that gogv follows, for Go
programs that print it, as gopuml's `--check-graphviz` does when it lays out
graphs with gogv.

## Changes

- `gogv.GraphvizVersion` (`"16.1.0"`): the version of Graphviz that gogv
  follows. `dot -V` names it before the version of gogv, and the SVG output
  names it in its `Generated by graphviz version` comment; both now take it
  from this one constant.

## Unchanged

The outputs of v0.1.0 are unchanged, byte for byte: the conformance results
against Graphviz 16.1.0 (565 cases: 501 passed, 26 known differences, 38 not
supported yet, 0 failed) and the hashes that CI compares across platforms are
the same.

## Installation

This release has no prebuilt binaries. With Go 1.26 or later:

```sh
go install github.com/ekalinin/gogv/cmd/dot@v0.2.0
dot -V   # dot - graphviz version 16.1.0 (gogv 0.2.0)
```

As a library:

```sh
go get github.com/ekalinin/gogv@v0.2.0
```
