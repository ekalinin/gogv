# gogv v0.4.0

This release lays out more graphs as Graphviz does, by following the
heuristics of Graphviz that probes of its outputs reveal: how it breaks ties
in the order within ranks and in the positioning, in which order it routes
edges, and how it draws flat edges over nodes and the labels of flat edges
with ports. It also adds tools to find and reduce the layouts that still
differ.

## Changes

- Layout:
  - the x positioning starts from the initial feasible tree of section 4.3
    of Gansner et al., and balances the parts of the tree with a zero cut
    value in the order of the tree's edges;
  - the initial order within ranks takes the sources of a component in the
    order of a depth-first search of it, and the sort by medians flips the
    nodes with equal medians on the passes down;
  - the shorter edges are routed first, and a routed edge keeps the edges
    routed after it clear of its curve, as section 5.1.1 of Gansner et al.
    describes;
  - a flat edge between nodes that are not neighbors goes over the nodes
    between them, as high as Graphviz draws it, and the drawing's box
    includes it;
  - the label of a flat edge with a port lies where Graphviz puts it.
- Conformance:
  - the report gives, for the gopuml corpora, the proxy of gopuml's
    contract: a `plain` size within 2%, every node and edge label center
    within 2% of the graph size, and an SVG at SSIM 0.90 or more;
  - `make reduce` reduces a graph whose layout differs from Graphviz's to a
    small graph that still differs, with the reference image;
  - 20 graphs reduced from issue #28 are curated cases, and a reduced case
    that leaves the known differences must pass the proxy.
- `BenchmarkRenderClasses` runs 11% faster than in v0.3.1.

## Changed output

Of the 573 inputs of v0.3.1's conformance corpora, 34 change in `plain` and
`svg`: the graphs with these ties, flat edges over nodes and labels.

## Conformance

Against Graphviz 16.1.0, 607 cases: 527 passed, 41 known differences, 39 not
supported yet, 0 failed. 279 of the 296 gopuml cases pass the proxy of
gopuml's contract, against 273 with the layouts of v0.3.1. Of the graphs of
issue #28, `history-style-1` and `group2681-history_style_all_forms-1` now
pass; the others remain known differences, with what each still needs in the
design of the change.

## Installation

This release has no prebuilt binaries. With Go 1.26 or later:

```sh
go install github.com/ekalinin/gogv/cmd/dot@v0.4.0
dot -V   # dot - graphviz version 16.1.0 (gogv 0.4.0)
```

As a library:

```sh
go get github.com/ekalinin/gogv@v0.4.0
```
