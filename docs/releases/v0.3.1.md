# gogv v0.3.1

This release opens the landing page of gogv at
https://ekalinin.github.io/gogv/, with a playground that lays out DOT in the
browser with the WebAssembly build of this release. The library, the command
line and the outputs are those of v0.3.0.

## Changes

- The landing page: what gogv is, the three ways to run it, its use with
  `go tool pprof`, the output formats, the installation, the conformance
  results, the clean-room sources and the license. Everything but the
  playground is readable without JavaScript.
- The playground: it lays out the DOT source as SVG while it is edited,
  shows the warnings as the command line words them and the syntax errors
  with their line, offers example graphs, and downloads the SVG. It loads
  its module only when it is reached. The module is built from
  `internal/playground` of this release, which uses only the public API of
  the library; it is not a public JavaScript API.
- `make site` assembles the site locally, with a WebAssembly build of the
  working tree. The push of a release tag deploys the site with the build of
  that release.

## Unchanged

The library and the command line are those of v0.3.0: no Go file of either
changed. The conformance results against Graphviz 16.1.0 are the same,
587 cases: 516 passed, 32 known differences, 39 not supported yet, 0 failed,
and so are the hashes that CI compares across platforms.

## Installation

This release has no prebuilt binaries. With Go 1.26 or later:

```sh
go install github.com/ekalinin/gogv/cmd/dot@v0.3.1
dot -V   # dot - graphviz version 16.1.0 (gogv 0.3.1)
```

As a library:

```sh
go get github.com/ekalinin/gogv@v0.3.1
```
