# gogv v0.1.0

The first release of gogv, a Go implementation of the Graphviz `dot` program
that follows Graphviz 16.1.0. It lays out graphs written in the DOT language
and writes them in the output formats of `dot`, as a Go library, a `dot`
command line and a WebAssembly module. It needs no cgo, no embedded
WebAssembly and no installed Graphviz. gogv is written clean-room, from
published papers, the Graphviz documentation and the observed behavior of
Graphviz, and contains no code of Graphviz or of its ports.

## Supported

- the whole DOT grammar
- the layered layout of `dot`: ranking, crossing minimization, positioning,
  and spline or polyline routing, top to bottom or left to right
  (`rankdir=LR`)
- 11 node shapes: `rect`, `box`, `rectangle`, `plaintext`, `point`,
  `ellipse`, `oval`, `circle`, `diamond`, `hexagon`, `octagon`
- clusters, nested, with labels; `rank=same|min|max|source|sink`
- plain-text labels, edge labels, `xlabel`, `headlabel` and `taillabel`
- table labels of empty cells, and node ports that attach edges to their
  cells
- 14 output formats: `svg`, `svg_inline`, `plain`, `plain-ext`, `canon`,
  `dot`, `gv`, `xdot`, `xdot1.2`, `xdot1.4`, `json`, `json0`, `dot_json`,
  `xdot_json`

The Status section of the README lists the supported attributes and values.

## Not supported yet

Color names (colors are written `#rrggbb`), styles such as `filled` and
`dashed`, other shapes such as `record`, `rankdir=BT` and `rankdir=RL`,
`splines=ortho`, compass points, text in table cells and HTML text markup,
fonts other than the Times, Helvetica and Courier families, and the other
layout engines. Each gives a warning or an error that names it, and a warning
also names the default used instead. Output formats other than the 14 above,
such as `png` and `pdf`, are reported as not recognized, as Graphviz reports
an unknown format.

## Conformance

`make conformance` compares gogv with Graphviz 16.1.0 built without Pango,
layer by layer: `canon` byte for byte, `plain` and `svg` by size and by the
structural similarity of the rasterized documents, the other formats by their
objects, attributes and drawing operations. On 565 cases (the 255 curated
cases of `testdata/conformance`, the 260 graphs that gopuml v0.3.0 sends to
`dot` and a variant of 36 of them with clusters, and 14 command line cases):

- 501 cases pass
- 26 cases are documented known differences
  (`testdata/conformance/known-differences.yaml`)
- 38 cases use a feature that is not supported yet
- 0 cases fail

## Determinism

The output is the same, byte for byte, on every platform: CI renders the
curated cases in every format on linux/amd64, on macOS/arm64 and in the
WebAssembly build, and compares the hashes.

## Installation

This release has no prebuilt binaries. With Go 1.26 or later:

```sh
go install github.com/ekalinin/gogv/cmd/dot@v0.1.0
dot -V   # dot - graphviz version 16.1.0 (gogv 0.1.0)
```

The command is named `dot`, as Graphviz's is: when Graphviz is installed too,
the `dot` found first in `PATH` runs.

As a library:

```sh
go get github.com/ekalinin/gogv@v0.1.0
```
