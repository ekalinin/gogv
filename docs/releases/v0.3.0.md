# gogv v0.3.0

This release draws the call graphs of `go tool pprof` as Graphviz does. With
gogv installed as `dot`, `go tool pprof -svg`, `-web` and the Graph view of
`-http` work without an installed Graphviz: nodes are filled with their
colors, hot edges are thicker and kept straight, residual edges are dotted,
tag nodes are boxes with depth, and the Graph view selects nodes by their
`id`. Dense graphs are also laid out several times faster.

## Changes

- Attributes that `go tool pprof` writes are supported, without a warning:
  - on nodes: `style=filled`, `fillcolor`, `shape=box3d`, `tooltip`, `id`;
  - on edges: `style=dotted`, `penwidth`, `weight`, `tooltip`,
    `labeltooltip`;
  - `style` takes a comma-separated list of supported styles, such as
    `filled,rounded`.
- Layout:
  - `weight` weighs edges in the ranking and in the positioning, as in
    Gansner et al.: heavy edges are kept short and straight;
  - `box3d` nodes are sized as boxes;
  - arrowheads of wider pens stop short of their nodes, and widen above 4
    points, as Graphviz draws them.
- `svg`:
  - fills, with the color that Graphviz chooses: `fillcolor`, else `color`,
    else `lightgrey`;
  - the outline of `box3d`, dotted edges and pen widths;
  - tooltips, in the `a` elements that Graphviz writes;
  - node groups take their `id`, edge groups are numbered in the order the
    edges are read, and groups are written in the order Graphviz writes
    them; an invisible edge leaves its comment, as in Graphviz.
- `plain`, xdot and JSON write the same styles, fills, pen widths and
  `box3d` outlines, as Graphviz writes them.
- `canon` breaks long strings after commas and equals signs too, as Graphviz
  does.
- The x positioning updates its network simplex tree in place after each
  pivot, as section 2.4 of Gansner et al. describes, instead of rebuilding
  it. On the dense class diagrams of issue #29, `dot -Tsvg` is 3 to 6 times
  as fast: 1.24 s instead of 6.16 s for 150 classes, and 20.6 s instead of
  119.5 s for 300 classes. The pivots are the same, so the outputs do not
  change.

## Changed output

For graphs without the new attributes, layouts are unchanged. On the 551
inputs of v0.2.0's conformance corpora, `plain` and `canon` are the same,
byte for byte. `svg` changes in 100 of them, only in the order and the ids
of its groups, and in 12 of these an invisible edge now leaves its comment.

## Conformance

Against Graphviz 16.1.0, 587 cases: 516 passed, 32 known differences, 39 not
supported yet, 0 failed. The cases now include 7 DOT files that
`go tool pprof` writes for CPU and heap profiles. The 6 new known
differences come from heuristics that gogv does not follow yet: the order
within ranks of large profiles, a labeled edge with a back edge between the
same nodes, and the dash phase of thick dotted edges.

## Installation

This release has no prebuilt binaries. With Go 1.26 or later:

```sh
go install github.com/ekalinin/gogv/cmd/dot@v0.3.0
dot -V   # dot - graphviz version 16.1.0 (gogv 0.3.0)
```

As a library:

```sh
go get github.com/ekalinin/gogv@v0.3.0
```

To use it with `go tool pprof`, put the `dot` that `go install` writes, in
`$(go env GOPATH)/bin`, before any other `dot` on the `PATH`.
